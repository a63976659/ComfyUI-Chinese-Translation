## プラグイン紹介

ComfyUI-Global-Translation は ComfyUI 用に設計された翻訳プラグインです。フロントエンドとバックエンドの連携により、ノード、メニュー、設定パネル、マネージャーなど目にするテキストすべてをリアルタイムで翻訳し、ComfyUI 公式のネイティブ翻訳と完全に共存します。翻訳先言語は ComfyUI 公式の言語設定（設定 → 一般 → `Comfy.Locale`）に自動で追従し、プラグイン自身の UI テキストは 15 言語に対応しています。

### なぜこのプラグイン？

| 特徴 | 本プラグイン | 他の翻訳プラグイン |
|------|--------|-------------|
| 公式翻訳との互換 | ✅ 公式の既存翻訳を上書きしない | ❌ 競合する可能性 |
| 右クリックメニュー | ✅ 翻訳後も機能が正常 | ❌ 一部の機能が不能 |
| 新旧 UI の互換 | ✅ デュアルボタン構造 | ❌ 単一バージョンのみ |
| リアルタイム切替 | ✅ 再起動不要 | ❌ 再起動が必要 |
| ユーザー定義タイトル保護 | ✅ 変更を上書きしない | ❌ 上書きされる可能性 |

## 主要な特徴

### 🎯 スマート翻訳システム

- **スマート検出** — 翻訳済みのテキストを自動識別し、重複翻訳や無限再帰を回避
- **ネイティブ翻訳との互換** — ComfyUI 公式翻訳と完全に共存し、互いに干渉しない
- **文脈認識** — 要素の種類（ノード、メニュー、ウィジェットなど）ごとに最適な翻訳戦略を採用
- **翻訳データのスマートマージ** — 複数の翻訳ファイルに同名ノードがある場合、相互補完でマージし、翻訳が消失しない
- **カスタムパネル翻訳** — ノード内部で作成されるパネル（ボタン、ラベル、ドロップダウン、ツールチップ、ポップアップなど）も自動で翻訳
- **コールバック保護** — 右クリックメニュー翻訳後も、切断・リネームなど全機能が正常に動作

### 🎨 美しいユーザーインターフェース

- **カプセル型セグメント** — 角丸カプセルのスライダートグル。青いスライダーが「入/切」間を滑らかに切り替わり、モダンな見た目
- **レインボーアニメーション** — 有効時は流れるような虹色のグラデーションを表示
- **グレーのミニマル設計** — 無効時は上品なグレーグラデーションを採用
- **ネイティブ低主張モード** — ComfyUI のデフォルトテーマに馴染む配色を選択可能
- **ライブ状態表示** — ボタンのテキストと色が現在の翻訳状態をリアルタイムに反映

### 🔧 柔軟な翻訳管理

- **リアルタイム切替** — 再起動せずに翻訳を ON/OFF
- **状態の永続化** — 設定は自動保存され、再起動後も維持
- **設定パネル統合** — ComfyUI の設定パネルでトグルのスタイルとドロップダウン翻訳を構成（言語は ComfyUI 公式設定に追従）
- **プラグイン単位の ON/OFF** — 設定パネル内蔵のマネージャーで特定プラグインの翻訳を無効化可能
- **追加即反映** — 新しい翻訳ファイルは再起動不要で反映

### 🛡️ 安定性と信頼性

- **万全な例外処理** — 主要な処理はすべてエラーハンドリング済み
- **グレースフルデグラデーション** — 翻訳失敗時は元のテキストに自動フォールバック
- **DOM 安全保護** — Vue/PrimeVue コンポーネントのイベントバインドを壊さない
- **複数バージョン対応** — ComfyUI の新旧インターフェースの両方に対応

## インストール

### 方法 1：Git クローン（推奨）

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

インストール後に ComfyUI を再起動してください。

#### 方法 1 — 初心者向け詳細手順：

1. プラグインフォルダ `ComfyUI\custom_nodes` を開く
2. Win11 は何もない場所を右クリックして「ターミナルで開く」。Win10 はアドレスバーに `cmd` と入力して Enter。
3. このページの右上の Code を展開し、アドレスをコピー（URL をそのままコピーでも可）
4. ターミナルに `git clone ` と入力し、アドレスを貼り付けて Enter。例：`git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. インストール完了。ComfyUI を再起動。（失敗した場合はプロキシ経由で再試行）



### 方法 2：ComfyUI Manager

1. ComfyUI Manager を開く
2. データを「チャンネル（リモート）」に変更
3. ノードマネージャーをクリック
4. **猪的飞行梦** で検索
5. インストールをクリックし、ComfyUI を再起動

### 方法 3：手動ダウンロード（非推奨、更新不可）

1. GitHub ページで **Code → Download ZIP** をクリック
2. `ComfyUI/custom_nodes/ComfyUI-Global-Translation` に解凍
3. ComfyUI を再起動

## 使い方

### 翻訳トグル

インストール後、界面に翻訳トグルボタンが表示されます。クリックで翻訳状態を切り替えます：

- **翻訳 ON** — ボタンが「翻訳オン」を表示し、界面テキストを現在の言語（ComfyUI 公式言語設定に追従）へ翻訳
- **翻訳 OFF** — ボタンが「翻訳オフ」を表示し、元の英語界面に戻す

### 翻訳言語

翻訳先言語はプラグイン内で個別に設定せず、**ComfyUI 公式の言語設定**（設定 → 一般 → 言語 / `Comfy.Locale`）に自動で追従します：

- 公式対応言語はすべてマッチ：簡体字中国語、繁体字中国語、英語、日本語、韓国語、ロシア語、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語(ブラジル)、トルコ語、アラビア語、ペルシア語、ヘブライ語。未対応言語は英語にフォールバック
- ComfyUI 設定で公式言語を切り替えるとページが自動リフレッシュし、翻訳とプラグイン UI テキストが同時に反映されます。手動再起動は不要

### 設定パネル

ComfyUI の設定 →「🌐 翻訳設定」に 2 つの項目があります。UI テキストは現在の言語にローカライズされ（15 言語）、どの言語でもセクションの並び順が一致します：

| 項目 | 説明 | オプション |
|-------|------|------|
| 🎨 トグルのスタイル | トグルの外観を選択。切り替えるとリフレッシュせず即時描画 | pill (カプセル) / gradient (レインボー) / plain (ネイティブ低主張) |
| 📋 ドロップダウン項目 | COMBO ドロップダウン内の選択肢テキストも翻訳するか | オン / オフ（変更後自動リフレッシュ） |

設定項目の下には**プラグイン翻訳マネージャー**パネルもあります。翻訳ファイルを持つプラグインが一覧表示され、チェックを外すとそのプラグインの翻訳を無効化できます。保存後自動リフレッシュ。

> 💡 **カプセル型セグメント（推奨）**：角丸カプセル形状で、青いハイライトスライダーが現在の状態を覆います。**青いスライダーをクリック**すると反対側へ滑って切り替わり、選択直後に設定ファイルへ保存、ComfyUI 再起動後も維持されます。

### ボタンスタイル一覧

| スタイル | オン時 | オフ時 | 向いている用途 |
|-----|---------|---------|----------|
| **カプセル型セグメント** | 青スライダーが「オン」を覆い、白太字 | 青スライダーが「オフ」へスライド、グレー文字 | モダンでミニマル、状態が一目瞭然 |
| **レインボーグラデーション** | 虹が流れるアニメ、白太字 | グレーが流れるアニメ、濃色太字 | 直感的で目立たせたい場合 |
| **ネイティブ低主張** | ComfyUI テーマ色の背景 | 濃色背景、グレー文字 | 界面に馴染ませたい場合 |

> **カプセル型セグメントの操作説明**：切り替えのトリガーは青いハイライトスライダーのみです。クリックするとスライダーがまず滑走アニメーション（約 300ms）を再生し、その後保存してページをリフレッシュします。グレーの文字セグメントは状態表示のみで、クリックしても反応しないのが仕様です。

### カスタム翻訳の追加

`ja-JP/Nodes/` 配下に JSON ファイルを作成するだけです：

```json
{
  "YourNodeClassName": {
    "title": "ノード表示名",
    "inputs": {
      "input_name": "入力名の翻訳"
    },
    "outputs": {
      "output_name": "出力名の翻訳"
    },
    "widgets": {
      "widget_name": "ウィジェット名の翻訳"
    },
    "ui": {
      "English text in panel": "パネル内の翻訳"
    }
  }
}
```

> **作成のコツ**
>
> - `widgets` のキーはウィジェットの**実際の名前**（ソース上のパラメータ名、例 `target_language`）を使う必要があります。画面表示の display_name（例 `Target Language`）ではありません。V3 API（io.Schema）プラグインでは、実際の名前と display_name の両方のキーを書くと互換性が最も高くなります
> - `ui` フィールドは、ノード内部のカスタムパネル（`addDOMWidget` で作成）内の英語テキストを翻訳するもので、キーは画面表示の英語原文、値は翻訳です
> - 「恒等翻訳」（キーと値が同一の項目、例 `"cfg": "cfg"`）は追加しないでください。翻訳として意味を持ちません
> - キーのスペルを確認してください。ソースと一致しない（例 `perturb_atttn` に t が余分）とそのウィジェットは翻訳されません

`ja-JP/Menus/` 配下に JSON ファイルを作成するとメニュー翻訳を追加できます：

```json
{
  "English Menu Text": "メニューテキストの翻訳",
  "Another Item": "別の項目"
}
```

> 翻訳ファイルを追加しても ComfyUI の再起動は不要です。翻訳トグルを切り替えるだけで反映されます。

## アーキテクチャ

### 全体構成

```
┌──────────────────────────────────────────────────────┐
│                    ComfyUI 本体                       │
│                                                        │
│  Python バックエンド (__init__.py)   フロント JS (js/) │
│  ├─ HTTP API ルーティング           ├─ main.js (翻訳エンジン)
│  ├─ 翻訳データのコンパイル          ├─ MenuTranslate.js     │
│  └─ 設定の永続化                    └─ utils.js (ユーティリティ)
│         │                             │                │
│         ▼                             ▼                │
│   ja-JP/ 翻訳データ              MutationObserver       │
│   ├─ Nodes/*.json              リアルタイム DOM 翻訳    │
│   ├─ Categories/*.json                                 │
│   └─ Menus/*.json                                      │
└──────────────────────────────────────────────────────┘
```

### 中核技術

| 技術 | 説明 |
|------|------|
| **コールバックラッピング (Callback Wrapping)** | 右クリックメニューのテキストを翻訳しつつ、基盤コールバックの content マッチングを保護 |
| **デュアルボタン構造** | 旧版 `.comfy-menu` と新版 `.comfyui-menu` の両 UI に対応 |
| **MutationObserver 監視** | DOM 変化をリアルタイム検知し、新しく現れた要素を自動翻訳 |
| **translatedValueSet** | Set により翻訳済みかを O(1) で判定し、重複処理を回避 |
| **葉ノード保護** | `innerText` を子を持たないノードのみに代入し、Vue のイベントバインドを守る |
| **Gzip 圧縮転送** | 翻訳データを Gzip 圧縮して転送し、ネットワーク負荷を削減 |

> 完全な技術詳細は [TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md) を参照してください

## 注意事項

### 互換性

- **翻訳プラグインとの競合** — 本プラグインは他の翻訳プラグイン（例 AIGODLIKE-ComfyUI-Translation）と競合します。使用前に他をアンインストールしてください
- **既知の競合プラグイン** — `ComfyUI Browser` は互換性の問題がある可能性があります
- **ブラウザ対応** — Chrome、Edge、360 ブラウザを推奨。その他は十分にテストしていません

### 動作環境

| コンポーネント | 要件 |
|------|------|
| ComfyUI | 最新版（新旧 UI に互換） |
| Python | 3.8+ |
| ブラウザ | Chrome / Edge（推奨） |

### 2026-07-27

**修正：V3 API ノードのウィジェット翻訳が効かない問題**

- V3 API（io.Schema）製のプラグイン（例 ComfyUI-qwenmultiangle）でウィジェットが翻訳されない問題を修正
- **原因**：V3 ノードはウィジェットに英語の `display_name` を宣言することが多く（name が `horizontal_angle`、label が `Horizontal Angle`）、旧判定は「label ≠ name」をネイティブ翻訳とみなしてスキップしていました
- **対策**：`isAlreadyTranslated` に正規化比較を追加。label が name の装飾表現（大文字小文字/スペース/アンダースコア/ハイフンの差）に過ぎない場合は翻訳済みとみなさない

**修正：恒等翻訳が翻訳済み判定セットを汚染**

- 特定のウィジェット（例 `cfg`）が全ノードで翻訳されない問題を修正
- **原因**：一部の翻訳ファイルに「恒等翻訳」（例 `"cfg": "cfg"`）があり、その値が `translatedValueSet` に入った結果、英語原名が「翻訳済み」と誤判定され、その名称の翻訳が全体でブロックされていました
- **対策**：判定セット構築時、キーと値が同一の項目をスキップ

**翻訳ファイルの修正**

- ComfyUI-LTXVideo のキーのスペル誤りを修正（`perturb_atttn`→`perturb_attn`、`cross_atttn`→`cross_attn`、`quantize_fnn`→`quantize_ffn`）
- ComfyUI-qwenmultiangle に不足していた実際のウィジェット名キー（`target_language`、`prompt`）を追加

### 2026-04-08

**修正：右クリックメニューの機能が壊れる問題**

- 翻訳オン時、出力ポートの右クリックメニューで「切断」「ポートをリネーム」などが反応しなくなる重大なバグを修正
- **原因**：LiteGraph は基盤で `value.content` の英語テキストマッチによりコールバックを振り分けており、翻訳後にマッチ失敗していました
- **対策**：コールバックラッピング（Callback Wrapping）を実装。コールバック実行の瞬間だけ英語に戻し、実行後に翻訳へ戻すことで、表示と機能の両立を実現
- `value.callback`（個別）と `options.callback`（共有）の両モードをラップ
- `_originalContent` による多重翻訳上書き保護を追加。キャンバスメニューが翻訳パイプラインを 2 度通っても原文を失わないよう防御

**修正：DOM 翻訳がイベントバインドを壊す問題**

- `replaceText` の `innerText` 代入が子要素や Vue/PrimeVue のリスナーを破壊する問題を修正
- **対策**：葉ノードチェック `target.children.length === 0` を追加し、子を持たないノードのみに `innerText` を代入
