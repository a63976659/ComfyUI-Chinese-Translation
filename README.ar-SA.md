## تعريف الإضافة

ComfyUI-Global-Translation هي إضافة ترجمة مصممة لـ ComfyUI. من خلال التعاون بين الواجهة الأمامية والخلفية، توفر ترجمة فورية للواجهة تغطي العُقد والقوائم ولوحة الإعدادات والمدير وكل نص مرئي، وتتعايش بشكل مثالي مع الترجمة الأصلية الرسمية في ComfyUI. تتبع لغة الترجمة تلقائيًا إعداد اللغة الرسمي في ComfyUI (الإعدادات ← العام ← `Comfy.Locale`)؛ تدعم نصوص واجهة الإضافة نفسها 15 لغة.

### لماذا تختار هذه الإضافة؟

| الميزة | هذه الإضافة | إضافات ترجمة أخرى |
|------|--------|-------------|
| متوافقة مع الترجمة الرسمية | ✅ لا تستبدل الترجمات الرسمية القائمة | ❌ قد تتعارض |
| وظائف القائمة السياقية | ✅ تظل تعمل بعد الترجمة | ❌ تتعطل بعض الوظائف |
| متوافقة مع الواجهة القديمة والجديدة | ✅ بنية زر مزدوج | ❌ إصدار واحد فقط |
| تبديل فوري | ✅ دون إعادة تشغيل | ❌ يتطلب إعادة تشغيل |
| حماية العناوين المخصصة | ✅ لا تستبدل تعديلات المستخدم | ❌ قد تُستبدل |

## الميزات الأساسية

### 🎯 نظام ترجمة ذكي

- **كشف ذكي** — يتعرف تلقائيًا على النص المترجم مسبقًا، مما يمنع الترجمة المتكررة والتكرار اللانهائي
- **توافق أصلي** — يتعايش بشكل مثالي مع الترجمة الرسمية في ComfyUI دون تدخل متبادل
- **وعي بالسياق** — يطبق الأنسب حسب نوع العنصر (عُقد، قوائم، عناصر تحكم، إلخ)
- **دمج ذكي للبيانات** — عندما تحتوي عدة ملفات ترجمة على نفس العقدة، تُدمج الإدخالات بشكل تكميلي بدل الاستبدال
- **ترجمة اللوحات المخصصة** — اللوحات المنشأة داخل العُقد (أزرار، تسميات، قوائم منسدلة، تلميحات، نوافذ منبثقة، إلخ) تُترجم تلقائيًا أيضًا
- **أمان الاستدعاءات** — بعد ترجمة القائمة السياقية، تظل جميع الوظائف (فصل، إعادة تسمية، إلخ) تعمل بشكل صحيح

### 🎨 واجهة مستخدم جميلة

- **زر تبديل على شكل حبوة مجزأة** — مفتاح مستدير بشكل حبوة مع مؤشر أزرق ينزلق بسلاسة بين قسمي "تشغيل/إيقاف"، بمظهر عصري
- **تأثير قوس قزح** — في الحالة النشطة يُظهر حركة متدرجة لقوس قزح سلسة
- **تصميم رمادي بسيط** — في الحالة غير النشطة يستخدم تدرجًا رماديًا أنيقًا
- **الوضع الأصلي الهادئ** — اختياريًا لوحة ألوان هادئة تتناسب مع السمة الافتراضية لـ ComfyUI
- **تغذية راجعة فورية** — نص الزر ولونه يعكسان حالة الترجمة الحالية في الوقت الفعلي

### 🔧 إدارة مرنة للترجمة

- **تبديل فوري** — تفعيل/تعطيل الترجمة دون إعادة تشغيل
- **حالة دائمة** — تُحفظ الإعدادات تلقائيًا وتبقى بعد إعادة التشغيل
- **التكامل مع لوحة الإعدادات** — تكوين نمط المفتاح وترجمة الخيارات المنسدلة من إعدادات ComfyUI (اللغة تتبع الإعداد الرسمي في ComfyUI)
- **تبديل لكل إضافة** — مدير مدمج يتيح تعطيل الترجمة لإضافات محددة
- **إضافة وتطبيق فوري** — ملفات الترجمة الجديدة تصبح فعالة دون إعادة تشغيل

### 🛡️ مستقر وموثوق

- **معالجة قوية للاستثناءات** — جميع العمليات الحرجة محمية
- **تراجع لائق** — عند فشل الترجمة يعود تلقائيًا إلى النص الأصلي
- **حماية DOM** — الترجمة لا تُعطّل ربط الأحداث لمكونات Vue/PrimeVue
- **تعدد الإصدارات المدعومة** — يدعم واجهتي ComfyUI القديمة والجديدة

## التثبيت

### الطريقة 1: الاستنساخ عبر Git (موصى بها)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

أعد تشغيل ComfyUI بعد التثبيت.

#### الطريقة 1 — شرح تفصيلي للمبتدئين:

1. افتح مجلد الإضافات `ComfyUI\custom_nodes`
2. في Win11، انقر بزر الماوس الأيمن على منطقة فارغة واختر "فتح في الطرفية". في Win10، اكتب `cmd` في شريط العنوان واضغط Enter.
3. انقر **Code** أعلى يمين هذه الصفحة وانسخ العنوان (يمكنك أيضًا نسخ الرابط)
4. في الطرفية اكتب `git clone `، ثم الصق العنوان واضغط Enter. مثال: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. اكتمل التثبيت، أعد تشغيل ComfyUI. (إذا فشل التثبيت، فعّل بروكسي/VPN وأعد المحاولة.)



### الطريقة 2: ComfyUI Manager

1. افتح ComfyUI Manager
2. غيّر المصدر إلى: القناة (عن بُعد)
3. انقر مدير العُقد
4. ابحث عن **猪的飞行梦**
5. انقر تثبيت وأعد تشغيل ComfyUI

### الطريقة 3: التنزيل اليدوي (غير موصى بها، بدون تحديثات)

1. من صفحة GitHub انقر **Code ← Download ZIP**
2. فك الضغط إلى `ComfyUI/custom_nodes/ComfyUI-Global-Translation`
3. أعد تشغيل ComfyUI

## الاستخدام

### مفتاح الترجمة

بعد التثبيت يظهر زر تفعيل الترجمة في الواجهة؛ انقر عليه لتبديل حالة الترجمة:

- **الترجمة مفعّلة** — يعرض الزر "الترجمة مفعّلة" ويُترجم نص الواجهة إلى اللغة الحالية (تتبع إعداد اللغة الرسمي في ComfyUI)
- **الترجمة معطّلة** — يعرض الزر "الترجمة معطّلة" وتُستعاد الواجهة الإنجليزية الأصلية

### لغة الترجمة

لم تعد لغة الترجمة تُضبط داخل الإضافة؛ بل **تتبع تلقائيًا إعداد اللغة الرسمي في ComfyUI** (الإعدادات ← العام ← اللغة / `Comfy.Locale`):

- تطابق جميع اللغات المدعومة رسميًا: الصينية المبسطة، الصينية التقليدية، الإنجليزية، اليابانية، الكورية، الروسية، الفرنسية، الألمانية، الإسبانية، الإيطالية، البرتغالية (البرازيل)، التركية، العربية، الفارسية، العبرية؛ واللغات غير المغطاة ترجع إلى الإنجليزية
- بعد تبديل اللغة الرسمية في إعدادات ComfyUI، تُحدَّث الصفحة تلقائيًا؛ وتُطبَّق الترجمة ونصوص الإضافة معًا دون إعادة تشغيل يدوية

### لوحة الإعدادات

في إعدادات ComfyUI ← «🌐 إعدادات الترجمة» يوجد خياران. تُترجَم نصوص الواجهة إلى اللغة الحالية (15 لغة) بترتيب أقسام متسق عبر جميع اللغات:

| الخيار | الوصف | الخيارات المتاحة |
|-------|------|------|
| 🎨 نمط المفتاح | اختر المظهر؛ يُعاد رسمه فورًا دون تحديث | pill (حبوة مجزأة) / gradient (قوس قزح) / plain (أصلي هادئ) |
| 📋 الخيارات المنسدلة | هل تُترجم أيضًا نصوص خيارات القوائم المنسدلة COMBO | مفعّل / معطّل (تحديث تلقائي عند التغيير) |

أسفل الخيارين توجد أيضًا لوحة **مدير ترجمة الإضافات**: تسرد جميع الإضافات ذات ملفات الترجمة — ألغِ تحديد واحدة لتعطيل ترجمتها؛ تُحدَّث الصفحة بعد الحفظ.

> 💡 **الحبوة المجزأة (موصى بها)**: شكل مستدير مع مؤشر أزرق بارز فوق الحالة الحالية. **انقر المؤشر الأزرق** لينزلق إلى الجهة الأخرى؛ يُحفظ الاختيار فورًا في ملف الإعداد ويبقى بعد إعادة تشغيل ComfyUI.

### مرجع أنماط الأزرار

| النمط | مفعّل | معطّل | الأنسب لـ |
|-----|---------|---------|----------|
| **الحبوة المجزأة** | مؤشر أزرق فوق قسم "تشغيل"، نص أبيض عريض | مؤشر أزرق منزلق إلى "إيقاف"، نص رمادي | عصري وبسيط، الحالة بلمحة بصر |
| **تدرج قوس قزح** | حركة قوس قزح سلسة، أبيض عريض | حركة رمادية سلسة، نص داكن عريض | تريد شيئًا لافتًا |
| **الأصلي الهادئ** | خلفية بلون سمة ComfyUI | خلفية داكنة، نص رمادي | تريد الاندماج مع الواجهة |

> **التفاعل مع الحبوة المجزأة**: المؤشر الأزرق البارز فقط هو ما يفعّل التبديل — عند النقر يشغّل أولًا حركة انزلاق (~300 مللي ثانية)، ثم يحفظ ويُحدِّث الصفحة؛ قسم النص الرمادي مجرد تسمية حالة وعدم الاستجابة للنقر هو سلوك مقصود.

### إضافة ترجمات مخصصة

أنشئ ملف JSON داخل `ar-SA/Nodes/`:

```json
{
  "YourNodeClassName": {
    "title": "اسم العرض لعقدتك",
    "inputs": {
      "input_name": "ترجمة اسم المدخل"
    },
    "outputs": {
      "output_name": "ترجمة اسم المخرج"
    },
    "widgets": {
      "widget_name": "ترجمة اسم عنصر التحكم"
    },
    "ui": {
      "English text in panel": "ترجمة نص اللوحة"
    }
  }
}
```

> **نصائح عند الكتابة**
>
> - يجب أن تستخدم مفاتيح `widgets` **الاسم الحقيقي** لعنصر التحكم (اسم المعامل في المصدر، مثل `target_language`)، لا اسم العرض الظاهر على الشاشة (مثل `Target Language`). بالنسبة لإضافات واجهة V3 (io.Schema)، اكتب كلاً من الاسم الحقيقي واسم العرض كمفاتيح للحصول على أفضل توافقية
> - حقل `ui` يترجم النص الإنجليزي داخل اللوحات المخصصة (المنشأة عبر `addDOMWidget`)؛ المفتاح هو النص الإنجليزي الظاهر على الشاشة، والقيمة هي الترجمة
> - لا تُضف "ترجمات مطابقة" (القيمة تساوي المفتاح، مثل `"cfg": "cfg"`) — فهي لا تحمل أي معنى
> - تحقق جيدًا من تهجئة المفاتيح؛ أي مفتاح يختلف عن المصدر (مثل حرف `t` زائد في `perturb_atttn`) سيفشل في الترجمة بصمت

أنشئ ملف JSON داخل `ar-SA/Menus/` لإضافة ترجمات للقوائم:

```json
{
  "English Menu Text": "ترجمة نص القائمة",
  "Another Item": "عنصر آخر"
}
```

> بعد إضافة ملفات الترجمة، لا حاجة لإعادة التشغيل — تبديل الترجمة يطبّقها مباشرة.

| التقنية | الوصف |
|------|------|
| **تغليف الاستدعاءات** | يترجم نص القائمة السياقية مع الحفاظ على مطابقة `content` للاستدعاء الأساسي |
| **بنية الزر المزدوج** | تدعم كلاً من الواجهة القديمة `.comfy-menu` والجديدة `.comfyui-menu` |
| **MutationObserver** | يراقب تغييرات DOM في الوقت الفعلي ويترجم العناصر الجديدة تلقائيًا |
| **translatedValueSet** | يستخدم Set للتحقق O(1) مما إذا كان النص مترجمًا مسبقًا، لتجنب العمل المكرر |
| **حماية الأوراق** | يسند `innerText` فقط للعقد التي لا فروع لها، لحماية ربط أحداث Vue |
| **نقل Gzip** | تُنقل بيانات الترجمة مضغوطة بـ Gzip لتقليل تكلفة الشبكة |

> لمزيد من التفاصيل التقنية، راجع [TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md)

## إخلاء المسؤولية

هذه الترجمة والمحتوى المشترك يخضعان لما يلي:

**غير تجاري**

هذه الترجمة عمل شخصي غير مدفوع الأجر؛ لم يتلقَّ صاحبها أي تعويض أو فائدة تجارية. الغرض منها فقط التعلم والمناقشة ومشاركة المعرفة.

**لا ضمان للدقة**

تبذل الترجمة قصارى جهدها لتكون أمينة للأصل، لكنها لا تضمن الدقة أو الاكتمال أو التحديث أو الملاءمة لغرض معين. يتحمل المستخدم أي مخاطر ونتائج ناتجة عن استخدام هذه الترجمة أو الاعتماد عليها.

**نسبة المصدر الأصلي**

حقوق النشر للمواد الأصلية التي تستند إليها هذه الترجمة (بما في ذلك على سبيل المثال لا الحصر النصوص والصور ومقاطع الفيديو) تعود إلى مؤلفيها أو أصحاب حقوقها الأصليين. لا تدّعي هذه الترجمة أي حقوق على المحتوى الأصلي.

**الرجوع إلى الأصل**

للقرارات المهمة أو الأثر القانوني أو التنفيذ التقني أو الحكم المهني، راجع دائمًا النسخة الرسمية الأصلية واعتمد عليها بدلًا من هذه الترجمة.

**حقوق محفوظة**

إذا رأى صاحب حقوق أن هذه الترجمة تنتهك حقوقه المشروعة، فيرجى التواصل معي فورًا وسأقوم بإزالتها أو معالجتها وفقًا لذلك.
