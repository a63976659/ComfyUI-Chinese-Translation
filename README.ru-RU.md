## О плагине

ComfyUI-Global-Translation — это плагин перевода, разработанный для ComfyUI. Благодаря совместной работе фронтенда и бэкенда он выполняет перевод интерфейса в реальном времени, покрывая узлы, меню, панель настроек, менеджер и весь видимый текст, при этом идеально сочетаясь с официальным нативным переводом ComfyUI. Язык перевода автоматически следует официальному языковому параметру ComfyUI (Настройки → Общие → `Comfy.Locale`); собственные строки интерфейса плагина поддерживают 15 языков.

### Почему этот плагин?

| Возможность | Этот плагин | Другие плагины перевода |
|------|--------|-------------|
| Совместимость с офиц. переводом | ✅ Не перекрывает существующий официальный перевод | ❌ Возможны конфликты |
| Функции контекстного меню | ✅ Работают после перевода | ❌ Часть функций ломается |
| Совместимость со старым и новым UI | ✅ Двойная кнопочная архитектура | ❌ Только одна версия |
| Мгновенное переключение | ✅ Без перезапуска | ❌ Требуется перезапуск |
| Защита пользовательских заголовков | ✅ Не перекрывает правки пользователя | ❌ Могут быть перезаписаны |

## Основные возможности

### 🎯 Умная система перевода

- **Умное обнаружение** — автоматически распознаёт уже переведённый текст, избегая повторного перевода и бесконечной рекурсии
- **Совместимость с нативным переводом** — идеально сосуществует с официальным переводом ComfyUI без взаимных помех
- **Учёт контекста** — применяет оптимальную стратегию в зависимости от типа элемента (узлы, меню, виджеты и т. д.)
- **Умное слияние данных** — если несколько файлов перевода содержат один и тот же узел, записи дополняюще объединяются, а не затирают друг друга
- **Перевод пользовательских панелей** — панели, создаваемые внутри узлов (кнопки, метки, выпадающие списки, подсказки, всплывающие окна и т. д.), также переводятся автоматически
- **Защита колбэков** — после перевода контекстного меню все функции (отключить, переименовать и т. д.) работают полностью корректно

### 🎨 Красивый интерфейс

- **Сегментированная кнопка-пилюля** — круглая кнопка-переключатель с синим ползунком, плавно скользящим между сегментами «вкл/выкл», современный вид
- **Радужная анимация** — в активном состоянии отображается плавная радужная градиентная анимация
- **Минималистичный серый дизайн** — в неактивном состоянии используется элегантный серый градиент
- **Незаметный нативный режим** — по желанию сдержанная расцветка в стиле темы ComfyUI
- **Обратная связь в реальном времени** — текст и цвет кнопки мгновенно отражают текущее состояние перевода

### 🔧 Гибкое управление переводом

- **Мгновенное переключение** — включать/отключать перевод без перезапуска
- **Сохранение состояния** — настройки сохраняются автоматически и переживают перезапуск
- **Интеграция в панель настроек** — в настройках ComfyUI можно задать стиль переключателя и перевод выпадающих опций (язык следует официальному параметру ComfyUI)
- **Переключение по плагинам** — встроенный менеджер позволяет отключать перевод для отдельных плагинов
- **Новые файлы вступают сразу** — добавленные файлы перевода применяются без перезапуска

### 🛡️ Стабильность и надёжность

- **Полная обработка исключений** — все ключевые операции обёрнуты
- **Корректная деградация** — при сбое перевода возвращается исходный текст
- **Безопасность DOM** — перевод не ломает привязку событий компонентов Vue/PrimeVue
- **Поддержка нескольких версий** — совместим со старым и новым интерфейсом ComfyUI

## Установка

### Способ 1: клонирование через Git (рекомендуется)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

После установки перезапустите ComfyUI.

#### Способ 1 — подробная инструкция для новичков:

1. Откройте папку плагинов `ComfyUI\custom_nodes`
2. На Win11 щёлкните правой кнопкой на пустом месте и выберите «Открыть в терминале». На Win10 введите `cmd` в адресной строке и нажмите Enter.
3. Нажмите **Code** в правом верхнем углу этой страницы и скопируйте адрес (можно скопировать и URL).
4. В терминале введите `git clone `, вставьте адрес и нажмите Enter. Пример: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. Готово — перезапустите ComfyUI. (Если установка не удалась, включите прокси/VPN и повторите.)



### Способ 2: ComfyUI Manager

1. Откройте ComfyUI Manager
2. Переключите источник данных на: Канал (удалённый)
3. Нажмите «Менеджер узлов»
4. Выполните поиск **猪的飞行梦**
5. Нажмите «Установить» и перезапустите ComfyUI

### Способ 3: ручное скачивание (не рекомендуется, без обновлений)

1. На странице GitHub нажмите **Code → Download ZIP**
2. Распакуйте в `ComfyUI/custom_nodes/ComfyUI-Global-Translation`
3. Перезапустите ComfyUI

## Использование

### Переключатель перевода

После установки в интерфейсе появляется кнопка переключателя перевода; нажимайте её для смены состояния:

- **Перевод включён** — кнопка показывает «перевод включён», текст интерфейса переводится на текущий язык (следует официальному языковому параметру ComfyUI)
- **Перевод выключен** — кнопка показывает «перевод выключен», возвращается исходный английский интерфейс

### Язык перевода

Язык перевода больше не задаётся внутри плагина — он **автоматически следует официальному языковому параметру ComfyUI** (Настройки → Общие → Язык / `Comfy.Locale`):

- Совпадение со всеми официально поддерживаемыми языками: упрощённый и традиционный китайский, английский, японский, корейский, русский, французский, немецкий, испанский, итальянский, португальский (Бразилия), турецкий, арабский, персидский, иврит; непокрытые языки откатываются к английскому
- После смены официального языка в настройках ComfyUI страница автоматически обновляется, перевод и строки интерфейса плагина вступают одновременно, ручной перезапуск не нужен

### Панель настроек

В ComfyUI Настройки → «🌐 Настройки перевода» доступны два параметра. Строки интерфейса локализованы на текущий язык (15 языков), порядок разделов едилен для всех языков:

| Параметр | Описание | Варианты |
|-------|------|------|
| 🎨 Стиль переключателя | Выбор внешнего вида; перерисовка мгновенно, без обновления | pill (сегментированная пилюля) / gradient (радужный) / plain (нативный незаметный) |
| 📋 Выпадающие опции | Переводить ли также текст опций в раскрывающихся списках COMBO | Вкл / Выкл (автообновление при изменении) |

Под параметрами также есть панель **Менеджер перевода плагинов**: перечислены все плагины с файлами перевода — снимите отметку, чтобы отключить перевод плагина; после сохранения страница обновляется.

> 💡 **Сегментированная пилюля (рекомендуется)**: круглая форма с синим подсвеченным ползунком поверх текущего состояния. **Нажмите синий ползунок**, чтобы он переместился на другую сторону; выбор сразу сохраняется в файл конфигурации и переживает перезапуск ComfyUI.

### Справочник стилей кнопок

| Стиль | Включено | Выключено | Для чего подходит |
|-----|---------|---------|----------|
| **Сегментированная пилюля** | Синий ползунок поверх сегмента «вкл», жирный белый текст | Синий ползунок переехал на «выкл», серый текст | Современный минимализм, состояние с одного взгляда |
| **Радужный градиент** | Переливающаяся радуга, жирный белый | Переливающийся серый, жирный тёмный | Хотите наглядно и заметно |
| **Нативный незаметный** | Фон в цвет темы ComfyUI | Тёмный фон, серый текст | Хотите слиться с интерфейсом |

> **Взаимодействие с сегментированной пилюлей**: триггером переключения является только синий подсвеченный ползунок — после нажатия он сначала проигрывает анимацию скольжения (~300 мс), затем сохраняет и обновляет страницу; серый текстовый сегмент — лишь метка состояния, и отсутствие реакции на его нажатие является задуманным поведением.


### Добавление собственного перевода

Создайте JSON-файл в каталоге `ru-RU/Nodes/`:

```json
{
  "YourNodeClassName": {
    "title": "Отображаемое имя узла",
    "inputs": {
      "input_name": "перевод имени входа"
    },
    "outputs": {
      "output_name": "перевод имени выхода"
    },
    "widgets": {
      "widget_name": "перевод имени виджета"
    },
    "ui": {
      "English text in panel": "перевод текста в панели"
    }
  }
}
```

> **Советы по написанию**
>
> - Ключи `widgets` должны использовать **настоящее имя** виджета (имя параметра в исходном коде, например `target_language`), а не отображаемый display_name (например `Target Language`). Для плагинов V3 API (io.Schema) рекомендуется писать оба ключа — настоящее имя и display_name — для наилучшей совместимости
> - Поле `ui` переводит английский текст внутри самодельных панелей узла (созданных через `addDOMWidget`): ключ — отображаемый английский оригинал, значение — перевод
> - Не добавляйте «тождественные переводы» (значение равно ключу, например `"cfg": "cfg"`) — они не несут переводческого смысла
> - Проверяйте орфографию ключей; несовпадение с исходным кодом (например лишняя `t` в `perturb_atttn`) приведёт к тому, что виджет не переведётся

Создайте JSON-файл в каталоге `ru-RU/Menus/`, чтобы добавить переводы меню:

```json
{
  "English Menu Text": "перевод текста меню",
  "Another Item": "другой пункт"
}
```

> После добавления файлов перевода перезапуск ComfyUI не нужен — достаточно переключить перевод.

## Архитектура

### Общая схема

```
┌──────────────────────────────────────────────────────┐
│                  Основная программа ComfyUI           │
│                                                        │
│  Python-бэкенд (__init__.py)     Фронт JS (js/)        │
│  ├─ Маршруты HTTP API           ├─ main.js (движок)    │
│  ├─ Компиляция перевода         ├─ MenuTranslate.js    │
│  └─ Сохранение настроек         └─ utils.js (утилиты)  │
│         │                             │                │
│         ▼                             ▼                │
│   Данные перевода ru-RU/          MutationObserver      │
│   ├─ Nodes/*.json              перевод DOM в реальном  │
│   ├─ Categories/*.json                                   │
│   └─ Menus/*.json                                      │
└──────────────────────────────────────────────────────┘
```

### Ключевые технологии

| Технология | Описание |
|------|------|
| **Обёртка колбэков (Callback Wrapping)** | Переводит текст контекстного меню, сохраняя корректную логику совпадения `content` у базового колбэка |
| **Двойная кнопочная архитектура** | Поддерживает и старый `.comfy-menu`, и новый `.comfyui-menu` |
| **Наблюдение MutationObserver** | Отслеживает изменения DOM и автоматически переводит появляющиеся элементы |
| **translatedValueSet** | Использует Set для O(1)-проверки, переведён ли текст, избегая повторной обработки |
| **Защита листовых узлов** | Присваивает `innerText` только узлам без детей, защищая привязку событий Vue |
| **Передача Gzip** | Данные перевода передаются сжатые Gzip для снижения сетевых затрат |

> Полные технические детали см. в [TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md)

## Примечания

### Совместимость

- **Конфликт плагинов перевода** — этот плагин конфликтует с другими плагинами перевода (например AIGODLIKE-ComfyUI-Translation); удалите их перед использованием
- **Известный конфликтующий плагин** — у `ComfyUI Browser` возможны проблемы совместимости
- **Поддержка браузеров** — рекомендуются Chrome, Edge, 360 Browser; другие браузеры недостаточно протестированы

### 2026-07-27

**Исправление: перевод виджетов узлов V3 API не работал**

- Исправлено отсутствие перевода виджетов у плагинов на V3 API (io.Schema), например ComfyUI-qwenmultiangle
- **Причина**: узлы V3 часто объявляют английский `display_name` для виджета (name `horizontal_angle`, label `Horizontal Angle`); старая проверка считала «label ≠ name» нативным переводом и пропускала
- **Решение**: в `isAlreadyTranslated` добавлено нормализованное сравнение — label, являющийся лишь украшенным name (различия регистра/пробелов/подчёркиваний/дефисов), не считается переведённым

**Исправление: тождественные переводы загрязняли множество переведённого**

- Исправлено: отдельные виджеты (например `cfg`) не переводились ни на одном узле
- **Причина**: в некоторых файлах были «тождественные переводы» (например `"cfg": "cfg"`); их значение попадало в `translatedValueSet`, и английское имя ошибочно считалось «уже переведённым», глобально блокируя перевод этого имени
- **Решение**: при построении множества пропускать записи, где значение равно ключу

**Исправления файлов перевода**

- Исправлены опечатки в ключах ComfyUI-LTXVideo (`perturb_atttn`→`perturb_attn`, `cross_atttn`→`cross_attn`, `quantize_fnn`→`quantize_ffn`)
- Добавлены недостающие ключи настоящих имён виджетов в ComfyUI-qwenmultiangle (`target_language`, `prompt`)

### 2026-04-08

**Исправление: поломка функций контекстного меню**

- Исправлен серьёзный баг: при включённом переводе действия «отключить» и «переименовать порт» в контекстном меню выхода не реагировали
- **Причина**: LiteGraph раздаёт колбэки по совпадению английского `value.content`; после перевода совпадение не срабатывало
- **Решение**: реализована обёртка колбэков (Callback Wrapping) — английский временно восстанавливается в момент выполнения колбэка, затем возвращаются перевод, что сохраняет и отображение, и корректную работу
- Оборачиваются оба режима: `value.callback` (индивидуальный) и `options.callback` (общий)
- Добавлена защита `_originalContent` от перезаписи при многократном переводе, чтобы меню холста не теряло исходное значение, дважды пройдя конвейер

**Исправление: перевод DOM ломал привязку событий**

- Исправлено: присваивание `innerText` в `replaceText` разрушало дочерние элементы и слушатели Vue/PrimeVue
- **Решение**: добавлена проверка листового узла `target.children.length === 0`, `innerText` присваивается только узлам без детей
