## 플러그인 소개

ComfyUI-Global-Translation은 ComfyUI를 위해 설계된 번역 플러그인입니다. 프런트엔드와 백엔드의 협업으로 노드, 메뉴, 설정 패널, 매니저 등 모든 표시 텍스트를 실시간 번역하며, ComfyUI 공식 기본 번역과 완벽하게 호환됩니다. 번역 언어는 ComfyUI 공식 언어 설정(설정 → 일반 → `Comfy.Locale`)을 자동으로 따르며, 플러그인 자체의 인터페이스 문구는 15개 언어를 지원합니다.

### 이 플러그인을 선택해야 하는 이유?

| 특성 | 본 플러그인 | 기타 번역 플러그인 |
|------|--------|-------------|
| 공식 번역 호환 | ✅ 기존 공식 번역을 덮어쓰지 않음 | ❌ 충돌 가능 |
| 우클릭 메뉴 기능 | ✅ 번역 후 기능 정상 동작 | ❌ 일부 기능 상실 |
| 구/신 버전 UI 호환 | ✅ 이중 버튼 구조 | ❌ 단일 버전만 지원 |
| 실시간 전환 | ✅ 재시작 불필요 | ❌ 재시작 필요 |
| 사용자 지정 제목 보호 | ✅ 사용자 수정을 덮어쓰지 않음 | ❌ 덮어써질 수 있음 |

## 핵심 기능

### 🎯 지능형 번역 시스템

- **지능형 감지** — 이미 번역된 텍스트를 자동 인식하여 중복 번역과 무한 재귀를 방지
- **기본 번역 호환** — ComfyUI 공식 번역과 완벽히 공존하며 서로 간섭하지 않음
- **문맥 인식** — 인터페이스 요소 유형(노드, 메뉴, 위젯 등)에 따라 가장 적합한 번역 전략 적용
- **번역 데이터 지능형 병합** — 여러 번역 파일에 동일 노드가 있을 때 상호 보완 병합하여 번역이 사라지지 않음
- **사용자 정의 패널 번역** — 노드 내부의 사용자 정의 패널(버튼, 레이블, 드롭다운, 툴팁, 팝업 등)도 자동 번역
- **콜백 안전 보호** — 우클릭 메뉴 번역 후에도 끊기·이름 바꾸기 등 모든 기능이 완전히 정상 동작

### 🎨 아름다운 사용자 인터페이스

- **캡슐 세그먼트 컨트롤** — 둥근 캡슐 형태의 슬라이딩 토글. 파란 슬라이더가 '켜기/끄기' 구간을 매끄럽게 전환되어 세련된 인상
- **무지개 동적 효과** — 활성 상태에서 부드러운 무지개 그라데이션 애니메이션 표시
- **회색 심플 디자인** — 비활성 상태에서 우아한 회색 그라데이션 적용
- **네이티브 저조용 모드** — ComfyUI 기본 테마와 일치하는 절제된 배색 선택 가능
- **실시간 상태 피드백** — 버튼 텍스트와 색상이 현재 번역 상태를 실시간 반영

### 🔧 유연한 번역 관리

- **실시간 전환** — 재시작 없이 번역 켜기/끄기
- **상태 영속화** — 설정이 자동 저장되어 재시작 후에도 유지
- **설정 패널 통합** — ComfyUI 설정 패널에서 토글 스타일과 드롭다운 옵션 번역 구성(번역 언어는 ComfyUI 공식 언어 설정을 자동 추적)
- **플러그인 단위 번역 토글** — 설정 패널 내장 매니저에서 특정 플러그인의 번역 해제 체크 가능
- **번역 추가 즉시 반영** — 새 번역 파일 추가 후 재시작 불필요

### 🛡️ 안정적이고 신뢰할 수 있음

- **완비된 예외 처리** — 모든 핵심 작업에 오류 처리 포함
- **우아한 폴백** — 번역 실패 시 원문으로 자동 복귀
- **DOM 안전 보호** — 번역이 Vue/PrimeVue 컴포넌트의 이벤트 바인딩을 손상시키지 않음
- **다중 버전 호환** — ComfyUI 구/신 버전 인터페이스 동시 지원

## 설치 방법

### 방법 1: Git 클론 (권장)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

설치 완료 후 ComfyUI를 재시작하세요.

#### 방법 1 — 초보자 상세 안내:

1. 플러그인 폴더 ComfyUI\custom_nodes 열기
2. Win11은 빈 공간에서 우클릭 후 '터미널에서 열기' 선택. Win10은 주소창에 cmd 입력 후 엔터.
3. 이 페이지 우측 상단의 Code를 펼쳐 주소 복사(URL을 그대로 복사해도 됨)
4. 명령창에 `git clone ` 입력 후 주소 붙여넣기하고 엔터. 예: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. 설치 완료, ComfyUI 재시작. (설치 실패 시 프록시를 켜고 재시도)



### 방법 2: ComfyUI Manager

1. ComfyUI Manager 열기
2. 데이터를 '채널(원격)'으로 변경
3. 노드 관리 클릭
4. **猪的飞行梦** 검색
5. 설치 클릭 후 ComfyUI 재시작

### 방법 3: 수동 다운로드 (비추천, 업데이트 불가)

1. GitHub 페이지에서 **Code → Download ZIP** 클릭
2. `ComfyUI/custom_nodes/ComfyUI-Global-Translation`에 압축 해제
3. ComfyUI 재시작

## 사용 방법

### 번역 토글

설치 후 인터페이스에 번역 토글 버튼이 나타납니다. 클릭하여 번역 상태를 전환합니다:

- **번역 켜기** — 버튼이 `번역 켜짐`을 표시하고, 인터페이스 텍스트를 현재 언어(ComfyUI 공식 언어 설정 추적)로 번역
- **번역 끄기** — 버튼이 `번역 꺼짐`을 표시하고, 원래의 영어 인터페이스로 복원

### 번역 언어

번역 언어는 더 이상 플러그인에서 개별 설정하지 않으며, **ComfyUI 공식 언어 설정**(설정 → 일반 → 언어 / `Comfy.Locale`)을 자동으로 따릅니다:

- 공식 지원 언어 모두 매칭: 간체 중국어, 번체 중국어, 영어, 일본어, 한국어, 러시아어, 프랑스어, 독일어, 스페인어, 이탈리아어, 포르투갈어(브라질), 터키어, 아랍어, 페르시아어, 히브리어. 미지원 언어는 영어로 폴백
- ComfyUI 설정에서 공식 언어를 전환하면 페이지가 자동 새로고침되며 번역과 플러그인 UI 문구가 동시에 반영됩니다. 수동 재시작 불필요

### 설정 패널

ComfyUI 설정 → '🌐 번역 설정'에 두 개의 구성 항목이 있습니다. UI 문구는 현재 언어로 현지화되며(15개 언어) 모든 언어에서 섹션 배열 순서가 일치합니다:

| 항목 | 설명 | 선택지 |
|-------|------|------|
| 🎨 토글 스타일 | 토글 외관 선택, 전환 후 즉시 새로고침 없이 재렌더 | pill (캡슐 세그먼트) / gradient (무지개 그라데이션) / plain (네이티브 저조용) |
| 📋 드롭다운 옵션 | COMBO 드롭다운 내 선택지 텍스트도 번역할지 여부 | 켜기 / 끄기 (수정 후 자동 새로고침) |

설정 항목 아래에는 **플러그인 번역 관리자** 패널이 함께 제공됩니다. 번역 파일을 가진 모든 플러그인이 나열되며, 체크를 해제하면 해당 플러그인의 번역을 비활성화할 수 있습니다. 저장 후 자동 새로고침.

> 💡 **캡슐 세그먼트(권장)**: 둥근 캡슐 형태로 파란 하이라이트 슬라이더가 현재 상태를 덮습니다. **파란 슬라이더를 클릭**하면 반대편으로 미끄러져 전환이 완료되고, 선택 즉시 설정 파일에 저장되어 ComfyUI 재시작 후에도 유지됩니다.

### 버튼 스타일 설명

| 스타일 | 켬 효과 | 끔 효과 | 사용 장면 |
|-----|---------|---------|----------|
| **캡슐 세그먼트** | 파란 슬라이더가 '켜기' 구간을 덮고 흰색 굵은 글씨 | 파란 슬라이더가 '끄기'로 미끄러지고 회색 글씨 | 모던 심플, 상태가 한눈에 |
| **무지개 그라데이션** | 무지개 흐름 애니메이션, 흰색 굵은 글씨 | 회색 흐름 애니메이션, 짙은 굵은 글씨 | 직관적으로 눈에 띄길 원할 때 |
| **네이티브 저조용** | ComfyUI 테마색 배경 | 짙은 배경, 회색 글씨 | 인터페이스에 녹아들길 원할 때 |

> **캡슐 세그먼트 조작 설명**: 전환 트리거는 파란 하이라이트 슬라이더뿐입니다. 클릭하면 슬라이더가 먼저 미끄러지는 애니메이션(약 300ms)을 재생한 뒤 저장하고 페이지를 새로고침합니다. 회색 텍스트 구간은 상태 표시용일 뿐이며 클릭해도 반응하지 않는 것이 정상 동작입니다.

## 번역 커버 범위

### 번역 내용

| 카테고리 | 커버 내용 | 상태 |
|------|---------|------|
| **노드 이름** | 모든 워크플로 노드의 제목과 표시 이름 | ✅ |
| **노드 속성** | 입/출력 포트, 위젯 레이블, 설명 | ✅ |
| **메뉴 시스템** | 메인 메뉴, 우클릭 메뉴, 컨텍스트 메뉴 | ✅ |
| **설정 패널** | ComfyUI 설정 대화상자 | ✅ |
| **매니저** | ComfyUI Manager 인터페이스 | ✅ |
| **템플릿 라이브러리** | 워크플로 템플릿 이름 | ✅ |
| **인터페이스 요소** | 버튼, 레이블, 툴팁, 검색 상자 | ✅ |
| **사용자 정의 패널** | 노드 자체 DOM 패널의 버튼, 레이블, 드롭다운, 툴팁, 팝업 | ✅ |
| **큐 정보** | 큐 크기 등 동적 텍스트 | ✅ |

### 번역 파일 구조

```
ko-KR/
├── Nodes/          # 노드 번역(제목, 입력, 출력, 위젯, 사용자 정의 패널)
│   └── internal.json
├── Categories/     # 노드 분류 번역
│   ├── Internal.json
│   └── Other.json
└── Menus/          # 메뉴 및 인터페이스 번역
    ├── Comfy设置菜单及管理器菜单.json
    ├── Comfy条件选项.json
    ├── Comfy模版汉化-zdfxm.json
    └── ...
```

> 다른 언어 디렉터리(`zh-CN/`, `zh-TW/`, `en-US/`, `ru-RU/`, `fr-FR/`, `de-DE/`, `es-ES/`, `it-IT/`, `pt-BR/`, `ar-SA/`, `tr-TR/`, `fa-IR/`, `he-IL/`)도 동일한 구조이며 현재 언어에 따라 자동 로드됩니다. 그중 `en-US/`는 다른 언어 플러그인의 노드를 영어로 복원하는 데 사용됩니다.

### 사용자 정의 번역 추가

`ko-KR/Nodes/` 디렉터리에 JSON 파일을 생성하면 됩니다:

```json
{
  "YourNodeClassName": {
    "title": "노드 표시 이름",
    "inputs": {
      "input_name": "입력 이름 번역"
    },
    "outputs": {
      "output_name": "출력 이름 번역"
    },
    "widgets": {
      "widget_name": "위젯 이름 번역"
    },
    "ui": {
      "English text in panel": "패널 내 번역"
    }
  }
}
```

> **작성 팁**
>
> - `widgets`의 키는 위젯의 **실제 이름**(소스 파라미터 이름, 예 `target_language`)을 사용해야 합니다. 화면에 표시되는 display_name(예 `Target Language`)이 아닙니다. V3 API(io.Schema) 플러그인의 경우 실제 이름과 display_name 키를 모두 작성하면 호환성이 가장 좋습니다
> - `ui` 필드는 노드 내부 사용자 정의 패널(`addDOMWidget`로 생성)의 영어 텍스트를 번역하는 것으로, 키는 화면 표시 영어 원문, 값은 번역문입니다
> - '항등 번역'(키와 값이 동일한 항목, 예 `"cfg": "cfg"`)은 추가하지 마세요. 번역 의미가 없습니다
> - 키 철자를 확인하세요. 소스와 불일치하면(예 `perturb_atttn`에 t를 오타) 해당 위젯은 번역되지 않습니다

`ko-KR/Menus/` 디렉터리에 JSON 파일을 생성하면 메뉴 번역을 추가할 수 있습니다:

```json
{
  "English Menu Text": "메뉴 텍스트 번역",
  "Another Item": "다른 항목"
}
```

> 번역 파일 추가 후 ComfyUI를 재시작할 필요 없이, 번역 토글만 전환하면 반영됩니다.

## 기술 아키텍처

### 전체 구조

```
┌──────────────────────────────────────────────────────┐
│                    ComfyUI 메인 프로그램               │
│                                                        │
│  Python 백엔드 (__init__.py)     프런트 JS (js/)       │
│  ├─ HTTP API 라우팅              ├─ main.js (번역 엔진) │
│  ├─ 번역 데이터 컴파일            ├─ MenuTranslate.js    │
│  └─ 설정 영속화                  └─ utils.js (유틸)     │
│         │                             │                │
│         ▼                             ▼                │
│   ko-KR/ 번역 데이터              MutationObserver      │
│   ├─ Nodes/*.json              실시간 DOM 번역         │
│   ├─ Categories/*.json                                 │
│   └─ Menus/*.json                                      │
└──────────────────────────────────────────────────────┘
```

### 핵심 기술

| 기술 | 설명 |
|------|------|
| **콜백 래핑 (Callback Wrapping)** | 우클릭 메뉴 텍스트를 번역하면서 하위 콜백의 content 매칭 로직 보호 |
| **이중 버튼 구조** | 구버전 `.comfy-menu`와 신버전 `.comfyui-menu` 두 UI 동시 호환 |
| **MutationObserver 감시** | DOM 변화 실시간 감지, 새로 나타난 요소 자동 번역 |
| **translatedValueSet** | Set 구조로 O(1) 번역 여부 판단, 중복 처리 방지 |
| **리프 노드 보호** | `innerText`를 자식이 없는 노드에만 대입하여 Vue 이벤트 바인딩 보호 |
| **Gzip 압축 전송** | 번역 데이터를 Gzip 압축 전송하여 네트워크 부하 감소 |

> 완전한 기술 세부 사항은 [TECHNICAL_DOCUMENTATION.md](TECHNICAL_DOCUMENTATION.md) 참조
