## הצגת התוסף

ComfyUI-Global-Translation הוא תוסף תרגום שנועד עבור ComfyUI. באמצעות שיתוף פעולה בין חזית לאחור, הוא מספק תרגום ממשק בזמן אמת המכסה צמתים, תפריטים, לוח הגדרות, מנהל וכל טקסט גלוי, והוא מתיישב להפליא עם התרגום הרשמי המובנה של ComfyUI. שפת התרגום עוקבת אוטומטית אחר הגדרת השפה הרשמית של ComfyUI (הגדרות ← כללי ← `Comfy.Locale`); טקסטי הממשק של התוסף עצמו תומכים ב־15 שפות.

### למה לבחור בתוסף הזה?

| תכונה | תוסף זה | תוספי תרגום אחרים |
|------|--------|-------------|
| תואם לתרגום רשמי | ✅ אינו דורס תרגומים רשמיים קיימים | ❌ עלול להתנגש |
| פונקציות תפריט לחיצה ימנית | ✅ ממשיכות לעבוד גם אחרי התרגום | ❌ חלק מהפונקציות נשברות |
| תואם לממשק ישן וחדש | ✅ ארכיטקטורת כפתור כפול | ❌ תומך בגרסה אחת בלבד |
| החלפה בזמן אמת | ✅ ללא הפעלה מחדש | ❌ דורש הפעלה מחדש |
| הגנה על כותרות מותאמות | ✅ אינו דורס שינויי משתמש | ❌ עלולים להידרס |

## תכונות ליבה

### 🎯 מערכת תרגום חכמה

- **זיהוי חכם** — מזהה אוטומטית טקסט שכבר מתורגם, ומונע תרגום חוזר ורקורסיה אינסופית
- **תאימות מובנית** — מתיישב להפליא עם התרגום הרשמי של ComfyUI ללא הפרעות הדדיות
- **מודעות להקשר** — מיישמת את האסטרטגיה המתאימה ביותר לפי סוג הרכיב (צמתים, תפריטים, ווידג'טים וכו')
- **מיזוג נתונים חכם** — כאשר קבצי תרגום מרובים מכילים את אותו הצומת, הרשומות ממוזגות באופן משלים במקום לדרוס זו את זו
- **תרגום פאנלים מותאמים** — גם פאנלים שנוצרו בתוך צמתים (כפתורים, תוויות, תפריטים נפתחים, רמזים, חלונות קופצים וכו') מתורגמים אוטומטית
- **בטיחות קריאות חוזרות** — לאחר תרגום תפריט הלחיצה הימנית, כל הפונקציות (נתק, שינוי שם וכו') ממשיכות לעבוד כשורה

### 🎨 ממשק משתמש יפה

- **פקד גלולה מפוצל** — מתג מעוגל בצורת גלולה עם מחוון כחול הגולש בחלקלקות בין פלגי "פועל/כבוי", מראה מודרני
- **אפקט קשת בענן** — במצב פעיל מציג אנימציה מדורגת זורמת של קשת בענן
- **עיצוב אפור מינימליסטי** — במצב לא פעיל עושה שימוש במדרון אפור אלגנטי
- **מצב מובנה דיסקרטי** — לבחירה, ערכת צבעים רגועה התואמת את ערכת הנושא המובנית של ComfyUI
- **משוב בזמן אמת** — טקסט הכפתור וצבעו משקפים מיד את מצב התרגום הנוכחי

### 🔧 ניהול תרגום גמיש

- **החלפה בזמן אמת** — הפעלה/כיבוי תרגום ללא הפעלה מחדש
- **מצב מתמשך** — ההגדרות נשמרות אוטומטית ושרודות הפעלות מחדש
- **שילוב בלוח ההגדרות** — הגדרת סגנון המתג ותרגום אפשרויות התפריט הנפתח בהגדרות ComfyUI (השפה עוקבת אחר ההגדרה הרשמית של ComfyUI)
- **מתג לכל תוסף** — מנהל מובנה מאפשר להשבית את התרגום של תוספים ספציפיים
- **הוספה והחלה מיידית** — קבצי תרגום חדשים נכנסים לתוקף ללא הפעלה מחדש

### 🛡️ יציב ואמין

- **טיפול חזק בחריגות** — כל הפעולות הקריטיות מוגנות
- **נסיגה הדרגתית** — במקרה של כשל בתרגום חוזר אוטומטית לטקסט המקורי
- **הגנת DOM** — התרגום אינו שובר את קישור האירועים של רכיבי Vue/PrimeVue
- **תמיכהרב־גרסתית** — תומך הן בממשק הישן והן החדש של ComfyUI

## התקנה

### שיטה 1: העתקה באמצעות Git (מומלצת)

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/a63976659/ComfyUI-Global-Translation.git
```

הפעילו מחדש את ComfyUI לאחר ההתקנה.

#### שיטה 1 — מדריך מפורט למתחילים:

1. פתחו את תיקיית התוספים `ComfyUI\custom_nodes`
2. ב־Win11, לחיצה ימנית על אזור ריק ובחירה "פתח במסוף". ב־Win10, הקלידו `cmd` בשורת הכתובת ולחצו Enter.
3. לחצו על **Code** בפינה הימנית העליונה של עמוד זה והעתיקו את הכתובת (אפשר גם להעתיק את ה־URL)
4. במסוף הקלידו `git clone `, הדביקו את הכתובת ולחצו Enter. דוגמה: `git clone https://github.com/a63976659/ComfyUI-Global-Translation.git`
5. ההתקנה הושלמה, הפעילו מחדש את ComfyUI. (אם ההתקנה נכשלת, הפעילו פרוקסי/VPN ונסו שוב.)



### שיטה 2: ComfyUI Manager

1. פתחו את ComfyUI Manager
2. שנו את מקור הנתונים ל: ערוץ (מרחוק)
3. לחצו על מנהל הצמתים
4. חפשו אחר **猪的飞行梦**
5. לחצו על התקן והפעילו מחדש את ComfyUI

### שיטה 3: הורדה ידנית (לא מומלצת, ללא עדכונים)

1. בדף GitHub לחצו על **Code ← Download ZIP**
2. חלצו את הקובץ ל־`ComfyUI/custom_nodes/ComfyUI-Global-Translation`
3. הפעילו מחדש את ComfyUI

## שימוש

### מתג התרגום

לאחר ההתקנה מופיע כפתור הפעלת תרגום בממשק; לחצו עליו כדי להחליף את מצב התרגום:

- **תרגום מופעל** — הכפתור מציג "תרגום מופעל" וטקסט הממשק מתורגם לשפה הנוכחית (עוקב אחר הגדרת השפה הרשמית של ComfyUI)
- **תרגום כבוי** — הכפתור מציג "תרגום כבוי" ומשחזר את ממשק האנגלי המקורי

### שפת התרגום

שפת התרגום אינה מוגדרת עוד בתוך התוסף; היא **עוקבת אוטומטית אחר הגדרת השפה הרשמית של ComfyUI** (הגדרות ← כללי ← שפה / `Comfy.Locale`):

- תואמת את כל השפות הנתמכות רשמית: סינית מפושטת, סינית מסורתית, אנגלית, יפנית, קוריאנית, רוסית, צרפתית, גרמנית, ספרדית, איטלקית, פורטוגזית (ברזיל), טורקית, ערבית, פרסית, עברית; שפות שאינן מכוסות חוזרות לאנגלית
- לאחר החלפת השפה הרשמית בהגדרות ComfyUI, הדף מתרענן אוטומטית; התרגום וטקסטי התוסף מוחלים יחד, ללא צורך בהפעלה מחדש ידנית

### לוח ההגדרות

בהגדרות ComfyUI ← «🌐 הגדרות תרגום» ישנן שתי אפשרויות. טקסטי הממשק מתורגמים לשפה הנוכחית (15 שפות) עם סדר מקטעים עקבי בכל השפות:

| אפשרות | תיאור | בחירות |
|-------|------|------|
| 🎨 סגנון המתג | בחרו את המראה; משתנה מיד ללא רענון | pill (גלולה מפוצלת) / gradient (קשת בענן) / plain (מובנה דיסקרטי) |
| 📋 אפשרויות נפתחות | האם לתרגם גם את טקסט האפשרויות בתפריטים נפתחים מסוג COMBO | פועל / כבוי (מתרענן אוטומטית בשינוי) |

מתחת לאפשרויות נמצא גם לוח **מנהל תרגום תוספים**: הוא מפרט את כל התוספים שיש להם קבצי תרגום — בטלו סימון של אחד כדי להשבית את תרגומו; הדף מתרענן לאחר השמירה.

> 💡 **גלולה מפוצלת (מומלצת)**: צורה מעוגלת עם מחוון כחול מודגש מעל המצב הנוכחי. **לחצו על המחוון הכחול** כדי להחליקו לצד השני; הבחירה נשמרת מיידית בקובץ ההגדרות ונשמרת גם לאחר הפעלה מחדש של ComfyUI.

### סימוכין סגנונות כפתורים

| סגנון | פועל | כבוי | מתאים ל |
|-----|---------|---------|----------|
| **גלולה מפוצלת** | מחוון כחול מעל פלג "פועל", טקסט לבן מודגש | מחוון כחול החליק ל"כבוי", טקסט אפור | מודרני ומינימליסטי, מצב במבט אחד |

> **אינטראקציית הגלולה המפוצלת**: רק המחוון הכחול המודגש מפעיל את ההחלפה — בלחיצה הוא תחילה מנגן אנימציית החלקה (~300 מ״ש), ואז שומר ומרענן את הדף; פלג הטקסט האפור הוא רק תווית מצב, העובדה שאינו מגיב ללחיצה היא התנהגות מכוונת.

### מבנה קבצי התרגום

```
he-IL/
├── Nodes/          # תרגומי צמתים (כותרת, כניסות, יציאות, ווידג'טים, פאנלים מותאמים)
│   └── internal.json
├── Categories/     # תרגומי קטגוריות צמתים
│   ├── Internal.json
│   └── Other.json
└── Menus/          # תרגומי תפריטים וממשק
    ├── Comfy设置菜单及管理器菜单.json
    ├── Comfy条件选项.json
    ├── Comfy模版汉化-zdfxm.json
    └── ...
```

> שאר תיקיות השפה (`zh-CN/`, `zh-TW/`, `en-US/`, `ja-JP/`, `ko-KR/`, `ru-RU/`, `fr-FR/`, `de-DE/`, `es-ES/`, `it-IT/`, `pt-BR/`, `ar-SA/`, `tr-TR/`, `fa-IR/`) חולקות את אותו המבנה ונטענות לפי השפה הנוכחית; `en-US/` משמשת לשחזור צמתים של תוספים לא־סיניים חזרה לאנגלית.

```json

    "outputs": {
      "output_name": "תרגום שם היציאה"
    },
    "widgets": {
      "widget_name": "תרגום שם הווידג'ט"
    },
    "ui": {
      "English text in panel": "תרגום טקסט הפאנל"
    }
  }
}
```

> **טיפי כתיבה**
>
> - המפתחות ב־`widgets` חייבים להשתמש ב**שם האמיתי** של הווידג'ט (שם הפרמטר במקור, למשל `target_language`), לא ב־display_name המוצג על המסך (למשל `Target Language`). עבור תוספים הכתובים ב־V3 API (io.Schema), רשמו הן את השם האמיתי והן את ה־display_name כמפתחות לקבלת התאימות הטובה ביותר
> - השדה `ui` מתרגם טקסטים באנגלית בתוך פאנלים מותאמים (שנוצרו באמצעות `addDOMWidget`); המפתח הוא הטקסט האנגלי המוצג על המסך, הערך הוא התרגום
> - אל תוסיפו "תרגומי זהות" (ערך השווה למפתח שלו, למשל `"cfg": "cfg"`) — אין להם שום משמעות
> - בדקו פעמיים את הכתיב של המפתחות; מפתח השונה מזה שבמקור (למשל `t` מיותר ב־`perturb_atttn`) ייכשל בשקט ולא יתורגם

צרו קובץ JSON תחת `he-IL/Menus/` כדי להוסיף תרגומי תפריטים:

```json
{
  "English Menu Text": "תרגום טקסט התפריט",
  "Another Item": "פריט אחר"
}
```

> לאחר הוספת קבצי תרגום אין צורך בהפעלה מחדש — החלפת התרגום מיישמת אותם.

- תוקן מצב שבו ווידג'טים מסוימים (למשל `cfg`) לעולם לא תורגמו באף צומת

- **תיקון**: דילג על רשומות שערכן שווה למפתח שלהן בעת בניית הקבוצה

**תיקון: שבירת פונקציות תפריט הלחיצה הימנית**

- תוקן באג חמור שבו, כאשר התרגום פעיל, פעולות כמו "נתק" ו"שינוי שם יציאה" בתפריט הלחיצה הימנית של יציאת צומת חדלו להגיב
